## ✨ Overview

**3ASYWEALTH** is part of the [3ASY.APP](https://www.3asy.app) suite - a collection of utilities and productivity tools. Track and calculate your personal wealth with **maximum privacy** and **zero data collection**.

### 🔒 Privacy Guarantee

```
✅ No server stores your data
✅ No external database
✅ No account required
✅ No registration needed
✅ No tracking or analytics
✅ 100% browser localStorage
✅ Full data export/import
```

### 🎯 Key Features

| Feature | Description |
|---------|-------------|
| 🔐 **Privacy-First** | Your data never leaves your device |
| 📊 **Rich Visualization** | Interactive charts and summary views |
| 📄 **PDF Reports** | Generate professional wealth reports |
| 📥 **Import/Export** | CSV/JSON for Excel/Google Sheets |
| 🌙 **Dark Mode** | Beautiful light and dark themes |
| 🌍 **Multilingual** | English, Italian, Spanish |

## 🚀 Quick Start 📖 How to Use

### 1️⃣ Assets Table

- **Add assets**: Click "Add Asset" and fill the form
- **Edit/Delete**: Use icons in the table
- **Filter**: Select a category from dropdown
- **Import/Export**: Use the menu (⋮) to import/export CSV or JSON
- **Demo Data**: Load sample data to test the app
- **Clear All**: Remove all data (with confirmation)

### 2️⃣ Summary View

- View total wealth and key metrics
- Pie and bar charts by category
- Detailed percentage breakdown
- **Generate PDF Report**: Export a professional report with all your data and charts

### 3️⃣ About Page

- Frequently asked questions
- Privacy guarantees
- Open source information
- Technical details

## 🛠️ Tech Stack

- ⚛️ **React 18** + **TypeScript**
- ⚡ **Vite** for build and development
- 🎨 **Tailwind CSS** + **Shadcn/UI** components
- 🐻 **Zustand** with localStorage persistence

- 🌍 **i18next** for internationalization (EN/IT/ES)
- 📄 **jsPDF** + **html2canvas** for PDF report generation
